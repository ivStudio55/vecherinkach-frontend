## Важный нюанс по текущей механике

Сейчас промокод в проекте применяется на странице магазина https://vecherinkach.ru/pricing при выборе пакета и оплате. То есть для Ozon есть два возможных варианта:

1. Оставить текущую механику: покупатель получает промокод, выбирает пакет на странице магазина, вводит код и получает скидку/бесплатный доступ.
2. Сделать отдельную страницу активации: покупатель вводит код, и пакет открывается без дополнительной оплаты на сайте.

Для Ozon удобнее второй вариант, но документы ниже составлены так, чтобы работал и первый вариант.

## Состав комплекта

- `user-agreement.md` - пользовательское соглашение сайта.
- `offer-and-license.md` - оферта и лицензионные условия на цифровой контент.
- `privacy-policy.md` - политика обработки персональных данных.
- `rights-holder-statement.md` - заявление правообладателя о собственном контенте.
- `refund-policy.md` - правила возврата для промокодов.
- `activation-instruction.md` - инструкция по применению/активации кода.
- `ozon-product-card-template.md` - шаблон карточки товара для Ozon.

## Что еще нужно решить перед запуском

- Срок действия промокодов на Ozon: например, 12 месяцев с даты покупки.
- Срок доступа после активации: бессрочно или ограниченный срок.
- Названия первых пакетов для продажи.
- Как выдавать код покупателю: вручную через сообщение Ozon или через заранее подготовленную инструкцию.
- Как гасить неактивированный код при возврате.

Важно: это практический шаблон, а не индивидуальное юридическое заключение. Перед массовыми продажами стоит показать финальную версию юристу.
