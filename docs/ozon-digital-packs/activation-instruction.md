# Инструкция по применению промокода

## Что вы покупаете

Вы покупаете цифровой промокод, который открывает доступ к дополнительному игровому пакету сервиса "Вечеринкач" или предоставляет скидку/бесплатный доступ к указанному пакету.

Базовые игры сервиса могут быть доступны бесплатно. Промокод относится только к дополнительному контенту, указанному в описании товара: набору вопросов, заданий или сценариев.

## Как применить промокод

1. Перейдите на сайт https://vecherinkach.ru.
2. Откройте магазин: https://vecherinkach.ru/pricing.
3. Выберите пакет, указанный в описании товара.
4. Введите промокод из заказа в поле промокода.
5. Нажмите кнопку применения промокода.
6. После успешного применения завершите оформление доступа, если это требуется интерфейсом сайта.

## Важные условия

- Промокод можно использовать один раз.
- Срок действия промокода указывается в описании товара на площадке продажи.
- После успешного применения промокод считается использованным.
- Возврат после применения промокода не предусмотрен.
- Доступ предоставляется только для личного некоммерческого использования внутри сервиса "Вечеринкач".
